Import Medias
Import media files from a source directory to the current system's media folders. Files will be matched to games using multiple matching algorithms.

Matching Algorithm: Files will be matched using the following priority:
  1. Exact filename match (without extension)
  2. Game name match
  3. Normalized ROM filename with parentheses
  4. Normalized ROM filename without parentheses
Import ROMs
Import ROM files from a source directory to the current system's ROM directory. Files will be validated against system extensions, and existing ROMs with the same filename will be replaced.
Choose a subdirectory from ./roms/currentsystem/media/import/
Import Behavior:
  • Only files with extensions matching the current system will be imported
  • If a ROM with the same filename already exists, it will be replaced
  • New ROMs will be moved to the system directory and added to gamelist.xml
  • Files are moved (not copied) from the source directory
